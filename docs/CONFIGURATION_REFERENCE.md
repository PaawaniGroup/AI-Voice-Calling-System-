# Configuration reference

_Generated by `python scripts/gen_config_docs.py` from `config/settings.py` (authoritative). Do not edit by hand._

Precedence: process environment > `.env` (development only) > defaults. Secrets come only from the environment or a secret manager.
Non-secret policy: `config/telephony.yaml`. Provider structure: `config/provider.example.yaml`.

**Failure behaviour (all parameters):** a type/range violation fails startup with a sanitized error naming the variable (never its value). Cross-field rules are in `Settings.problems()`; production-like environments additionally require secrets and forbid the mock provider. **Environment column:** `all` unless noted; *dev-only* values trigger a warning (or an error in staging/production when unsafe).
